04 / Chunking

段落优先，
字符预算兜底

  1. 连续 3 行以上空行压缩为 2 行
  2. 先按 Markdown 空段落切成语义单元
  3. 超长单元优先按中英文句末标点切分
  4. 仍超长则按固定字符数硬切
  5. 组装到约 700 字符，并携带上一块末尾 120 字符
Chunk 01

段落 A · 段落 B · 句子 C …

← 120 chars overlap

句子 C … 段落 D · 段落 E

← context retained

段落 E … 段落 F

07 / Rank fusion

不硬加分数，
只融合排名

BM25 与余弦相似度量纲不同。两路各召回 20 条，通过稳定 Chunk ID 去重，再用 RRF 生成统一排名。

RRF(d) = Σ 1 / (1 + rankᵢ(d))
BM25精确词候选TOP 20
VECTOR语义候选TOP 20
FUSION去重后的证据TOP 5

为什么 k = 1

固定评测显示默认 k=60 会让“两路低排名”压过“单路高排名”。调至 1 后，Recall@5 从 78.57% 提升到 89.29%。
